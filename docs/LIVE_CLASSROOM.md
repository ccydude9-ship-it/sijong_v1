# 태블릿 6대와 전자칠판 실시간 수업

학생용 화면은 `index.html` 한 파일입니다. 파일을 직접 열면 기존처럼 현재 기기에 저장합니다. 서버로 같은 파일을 제공하면 로그인과 2초 간격 자동 갱신이 켜집니다. 화면에 표시되는 ‘교실 연결됨’과 마지막 확인 시각으로 연결 여부를 확인합니다.

## 수업에서 사용하는 순서

1. 선생님 컴퓨터에서 온라인 수업 주소를 열고 오른쪽 위 **⚙**를 누릅니다.
2. 최초 설정한 선생님 비밀번호로 접속합니다. 이름·사진·일과카드 자료를 준비합니다.
3. **이 자료로 수업 열기**를 누르고 표시되는 교실 코드를 학생에게 알려줍니다.
4. 학생 태블릿은 같은 웹주소에서 게임 시작 → 교실 코드 → 자기 이름 순서로 들어갑니다.
5. 선생님은 **공유모드 열기**를 누릅니다. 위 3명·아래 3명으로 학생별 상태가 표시됩니다. 미완성 상태에서도 이름을 누르면 입력한 답이나 현재 카드 배열이 보입니다.
6. 활동이 끝나면 선생님 설정에서 수업을 마칩니다. 카드 순위나 점수는 표시하지 않습니다.

활동 화면 오른쪽 위에 홈과 설정 톱니바퀴가 있습니다. 시간 입력창과 발표 확대창에는 X 닫기를 표시합니다. 홈을 누르면 진행 중인 답과 연습 횟수를 초기화합니다. 완성된 일과표는 발표를 위해 남겨 두며, 실전모드를 다시 시작할 때 초기화합니다. 공유화면에서 일과카드를 누르면 크게 열리고, 확대된 카드를 누르면 그림과 시계를 번갈아 보여 줍니다. 온라인 학생 기기에서 설정이나 공유모드를 열려면 선생님 비밀번호가 필요합니다. 설정의 ‘이전 화면으로’는 진행 중이던 화면으로 돌아갑니다.

### 이미 준비한 사진과 카드 가져오기

사진을 넣은 개인용 HTML은 공개 저장소에 포함하지 않습니다. 개인용 파일의 ⚙ → 자료 내보내기로 JSON을 내려받고, 온라인 수업의 선생님 설정에서 자료 불러오기로 등록하세요. 사진 묶음도 이 JSON에 포함됩니다. 자료를 불러온 뒤 **이 자료로 수업 열기** 또는 **수정한 자료로 수업 다시 열기**를 누르면 태블릿에 적용됩니다.

자료를 다시 열면 기존 학생 연결을 해제하고 교실 코드를 새로 만듭니다. 학생들은 다시 연결합니다. 수업 중에는 준비 자료를 바꾸기보다 공유화면을 사용하는 것을 권장합니다.

### 연결이 끊겼을 때

학생 입력은 우선 기기에 보관하고 연결이 돌아오면 다시 보냅니다. 교실 연결이 만료되면 다시 연결하라는 안내가 나타납니다. 같은 학생을 두 기기에서 동시에 수정해 기록이 겹치면 자동으로 덮어쓰지 않고 저장된 기록을 확인하도록 안내합니다. 보내지 못한 답이 있을 때는 탭을 닫거나 이름을 바꾸지 마세요.

## 개발 및 배포 담당자

기존 Express 인증, CSRF, SQLite와 로그인 시도 제한을 재사용합니다. `/api/live/setup`은 교사 전용이고, 학생의 쓰기 권한은 세션에 선택된 학생 한 명으로 제한됩니다. `/api/live/progress`는 학생에게 자신의 기록만 반환합니다. `/api/live/state`는 수업 자료를 반환하되 다른 학생의 진행 기록을 제거합니다. 재전송에는 요청 식별자와 revision을 사용합니다. 사진은 초기 자료를 받을 때만 전달하고, 주기적 조회에는 작은 진행 기록만 전달합니다.

Node.js 24에서:

```sh
npm ci
npm run start:classroom
```

실행 전에 아래 환경변수를 비공개 `.env` 또는 호스팅 설정에 지정해야 합니다.

| 변수                      | 값                                          |
| ------------------------- | ------------------------------------------- |
| `SIJONG_TEACHER_PASSWORD` | 최초 선생님 비밀번호, 8자 이상              |
| `SIJONG_PUBLIC_ORIGIN`    | 실제 접속 주소, 운영 환경에서는 `https://…` |
| `SIJONG_DATA_DIR`         | SQLite·서버 키를 보관하는 영속 디스크 경로  |
| `HOST`                    | 호스팅에서는 `0.0.0.0`                      |
| `PORT`                    | 호스팅에서 지정하는 포트, 기본 3000         |
| `NODE_ENV`                | 배포 시 `production`                        |

`Dockerfile.classroom`은 위 서버를 실행하는 배포용 이미지 정의입니다. HTTPS를 제공하는 호스트와 영속 디스크가 필요하며 한 서버 인스턴스로 실행합니다. 무료 호스팅 여부·비용은 선택한 서비스에 따라 다릅니다. 비밀번호와 학생 자료를 GitHub에 넣지 않습니다. `/api/health`를 상태 검사에 사용할 수 있습니다. 서버를 정지하고 데이터 디렉터리 전체를 백업하면 진행 기록과 로그인 키도 함께 보존됩니다.

기존 React 서버 버전과 섞이지 않도록 `start:classroom`의 기본 데이터 디렉터리는 `.local/live-classroom`입니다. 기존 `npm start` 동작은 바꾸지 않습니다.

```sh
npm run typecheck
npm test
npm run test:e2e -- tests/e2e/single-file.spec.ts tests/e2e/live-classroom.spec.ts --project=chromium
```

이 저장소에서 구현·테스트하는 것만으로 공개 수업 주소가 생기지는 않습니다. 실제 배포에는 사용할 호스팅 계정, HTTPS 주소와 영속 저장공간을 연결하는 단계가 남습니다.

검증 범위: 실제 Node 서버를 사용하는 브라우저 검사와 학생 6명의 동시 저장 검사를 통과했습니다. 실제 태블릿·공개 호스팅 검사는 아직 수행하지 않았습니다. 이 개발 환경에서는 컨테이너 내부 패키지 다운로드 연결이 완료되지 않아 Docker 이미지 빌드 검증도 남아 있습니다.

# 웹앱 기능 명세 (확정 설계 기반)

> 구현 상태: **첫 개발 버전 구현**. 아래는 학습 기능의 요구사항입니다. 최신 화면 흐름과 기술 결정은 [상세 설계](superpowers/specs/2026-10-14-clock-learning-app-design.md), 실제 확인 범위와 남은 검증은 [검증 기록](VALIDATION.md)을 참고합니다.

## 1. 사용자와 기기

- 학생 6명이 각각 가로형 태블릿으로 독립적으로 학습한다.
- 교사는 전자칠판에서 별도의 대시보드로 진행 상황 및 완성된 일과표를 확인한다.
- 학생 화면에서는 본인의 카드만 사용한다.
- 실시간 동기화는 백엔드로 구현한다. localStorage는 다른 기기로 자료를 보내지 못한다.

## 2. 카드 데이터

- 학생별 8개의 카드.
- 앞면: 학생이 손그린 활동 그림 + 활동명 (이미지로 준비).
- 뒷면: 정확한 바늘 위치가 표시된 시계 이미지.
- 카드의 정답 시각: `hour` (1~12), `minute` (0 또는 30).
- 실제 순서 배열을 위해 필요시 오전·오후 또는 하루 기준 순서값을 별도로 둔다. **같은 시각이 반복되면 배열 정답 판정이 애매하므로 준비 과정에서 조정**한다.
- 실명이나 개인정보 대신 개발·테스트 시 가명 사용.

## 3. 연습모드 — '째깍! 읽어 봐'

- 정각·30분을 포함한 바늘시계 문제를 계속 무작위 출제한다. 고정된 10문제 제한 없음.
- 화면에 큰 시계와 **시(1~12), 분(00/30)** 입력 버튼을 제공한다.
- 학생이 답을 입력하고 확인한다.
- 정답 시 긍정 피드백(시각적/효과음) 제공. 해당 시각과 일치하는 개인 카드가 있으면 보여줄 수 있도록 한다.
- 오답 시 정답을 즉시 노출하지 않고, 바늘 확대 등 선택 가능한 힌트와 재도전 기회를 제공한다.
- 카드가 연결되지 않은 시각이어도 연습이 중단되지 않도록 일반 정답 피드백으로 처리한다.
- 교사는 정해진 시간에 연습을 종료하고 다음 모드를 안내한다.

## 4. 실전모드 — '착착! 맞춰 봐'

**1단계: 카드의 시각 읽고 입력하기**

1. 개인 일과 카드 **8장**의 앞면(그림)을 무작위 순서로 보여준다.
2. 카드를 터치하면 뒤집혀 아날로그 시계가 보인다.
3. 각 카드의 시각을 보고 학생이 **시·분을 직접 선택하여 입력**한다.
4. 확인 시 잘못 입력한 항목의 **시각 입력 영역**만 가는 빨간 테두리로 표시한다. 정답은 제시하지 않는다.
5. 학생은 스스로 다시 읽고 수정할 수 있다.

**2단계: 시간순 배열하기**

1. 학생이 읽은 시각을 근거로 8장 카드를 이른 시각부터 늦은 시각까지 배열한다.
2. '완성하기'로 결과를 확인한다.
3. 순서가 잘못된 경우 해당 **카드 영역**만 가는 빨간 테두리로 표시해 시각 입력 오류와 구분한다.
4. 학생이 수정하고 재확인한다.
5. 완료 결과를 교사 대시보드에 전송한다.

> 1학년 학생이 태블릿에서 8개의 시각을 입력하고 배열하는 활동은 실제 수업 전에 조작 테스트와 소요 시간 측정이 필요하다. 화면 배치 및 단계 전환의 세부 UX는 구현·실험 과정에서 확정한다.

## 5. 공유모드 — '찰칵! 들려줘'

- 교사는 스마트보드의 독립된 대시보드에서 6명의 진행 상황과 완성된 시간순 일과표를 열어 본다.
- 학생마다 생활이 다르다는 점을 짧게 공유한다.
- 각 학생은 **실물 양면 카드 한 장**을 스스로 골라 시계가 그려진 뒷면을 친구들에게 보여 준다.
- 친구들이 시각을 읽으면 앞면의 그림을 보여 주고, 좋아하는 시간 또는 앞으로 지키고 싶은 일과를 설명한다.
- 발표가 길어지지 않도록 한 학생당 한 장을 중심으로 진행한다.

## 6. 자기주도 학습을 위한 피드백 원칙

- 학생의 첫 시도가 틀렸더라도 답을 일방적으로 알려주지 않는다.
- 오류 위치를 **최소한으로 표시**하고 자가 교정하도록 한다.
- 교사 도움은 기기 조작과 학습을 지속하기 위한 발판으로 제한한다.
- 완료 기록은 평가와 공유를 위한 것으로 공개 순위표·경쟁 점수판을 만들지 않는다.

## 7. 첫 개발 버전의 기술 결정

- React + Node.js 24 + Express + SQLite, SSE로 실시간 진행 공유
- 교사가 태블릿을 학급에 연결한 뒤 학생이 이름 선택, 교사는 별도 비밀번호로 접속
- 교사 준비 화면의 카드 이미지 교체, 비공개 서버 저장 및 범위별 접근 검사
- 학생 진행·완료 결과 서버 저장, 교사 대시보드에 반영
- 오전·오후를 포함한 하루 기준 분 값으로 배열, 같은 하루 시각 중복 금지
- 효과음 켜기·끄기, 터치·키보드 조작, 메모리 초안 보존과 재연결 복구
- 오락실 타이틀 → 이름 선택 → 모드 자유 선택, 모든 모드에서 같은 학생의 홈으로 복귀

## 8. 디자인 방향

- 1학년이 사용하기 쉬운 큼직한 버튼과 간단한 문구
- 카드 앞면(활동 그림) ↔ 뒷면(바늘시계) 뒤집기
- 카드 본문과 시각 입력칸은 별도 영역으로 구분해 서로 다른 오류를 표시
- 수업 프로젝트 '시계는 째깍! 하루는 찰칵!'의 **카메라 렌즈 안 시계** 모티브를 앱 아이콘과 시작 화면에 반영

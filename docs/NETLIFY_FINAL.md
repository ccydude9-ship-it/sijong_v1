# 최종 배포 방식: Netlify 정적 앱

이 문서는 이전 실시간 서버 배포 계획보다 우선합니다.

사용자는 실시간 진행 수집을 사용하지 않기로 결정했습니다. 학생 태블릿은 독립적으로 연습·입력·배열하고 선생님 컴퓨터는 준비된 일과카드를 발표 자료로 보여줍니다.

- 공유화면의 진행률/접속 상태는 숨깁니다.
- 학생 선택 후 설정된 오전·오후 포함 시각을 기준으로 8장을 정렬합니다.
- 이 기기에 저장된 입력 답, 배열, 완료 여부가 발표 순서를 바꾸지 않습니다.
- 시계/그림 전환, 확대 및 이전·다음 이동은 유지합니다.
- 각 기기의 활동은 해당 브라우저에 저장되며 기기 간 자동 전송은 없습니다.

## 배포
1. 제공된 `netlify-classroom-final.zip`을 압축 해제합니다.
2. 안에 있는 `netlify-classroom` 폴더를 Netlify Drop(https://app.netlify.com/drop)에 올립니다.
3. 폴더 최상단에는 `index.html`, `_headers`, `robots.txt`가 있어야 합니다.
4. 생성된 주소를 선생님 컴퓨터와 학생 태블릿에서 엽니다. 교실 코드나 별도 서버 설정은 없습니다.
5. 실제 태블릿 한 대에서 카드 입력·정답 확인을 점검한 뒤 나머지 기기에 같은 주소를 전달합니다.

제공되는 개인용 배포 파일에는 실제 학생 사진·48장 그림·최종 시각과 가장자리 표시 보정이 포함됩니다. 공개 저장소의 `index.html`은 가명/예시 자료이므로, 저장소를 그대로 Netlify에 연결하면 실제 수업 자료가 들어가지 않습니다.

`_headers`와 `robots.txt`는 검색 노출을 억제할 뿐 접근을 차단하지 않습니다. 배포 주소를 아는 사람은 실제 학생 자료를 열 수 있습니다. 링크는 수업 대상에게만 공유하고 학교 정책에 따라 필요한 접근 제한을 호스팅에서 설정합니다.

설정에서 수정한 내용은 현재 브라우저에 저장됩니다. 다른 기기에 똑같이 적용하려면 HTML을 다시 만들거나 자료를 각 기기에 가져와야 합니다. 배포 ZIP 자체가 브라우저 수정에 따라 자동 변경되지는 않습니다.

# 준비 및 개발 체크리스트

## 수업 자료
- [ ] 학생마다 일어나기·잠자기를 포함한 일과 8가지 선택
- [ ] '일과 생각판'으로 선택을 돕되 나머지 6가지는 학생에게 선택권 제공
- [ ] 가정과 연계해 일과의 실제 시각 조사
- [ ] 정각·30분 학습 범위에 맞춰 시각 연결, 같은 시각 중복 확인
- [ ] 학생 손그림 스캔 후 카드 앞면(그림·활동명) 제작
- [ ] 뒷면 시계 그림과 맞는지 학생별 검수
- [ ] 발표용 실물 양면 카드 인쇄

## 웹앱
- [ ] 연습모드 무제한 랜덤 시계 출제 및 재도전
- [ ] 정각/30분 시·분 입력 버튼
- [ ] 자가 교정용 힌트
- [ ] 정답 시 개인 카드 연결(매칭되는 카드가 없을 때 예외 처리)
- [ ] 실전 1단계 8장 카드 뒤집기 및 시각 입력
- [ ] 실전 2단계 8장 시간순 배열
- [ ] 시각 입력 오류와 카드 배열 오류를 구분하여 강조
- [ ] 완료·재도전·진행 상태 관리
- [ ] 백엔드 연결과 6기기 동시 사용
- [ ] 별도 교사용 실시간 대시보드
- [ ] 교실 전자칠판에서 공유 화면 확인
- [ ] 교사·학생 사용성 테스트 및 40분 수업 리허설

# 개발 버전 검증 기록

확인일: 2026-10-15 (한국 시간). 이 기록은 현재 클라우드 작업 머신에서의 결과이며 실제 교실 배포나 새 작업 머신에서의 복원을 증명하지 않습니다.

## 확인한 범위

- Node.js 24.19.0, npm 11.9.0에서 고정 lockfile 설치, 타입 검사, 제품 화면 빌드.
- 서버·도메인 테스트 90개, 화면·저장 테스트 34개 통과.
- 설치된 Debian Chromium 154에서 브라우저 테스트 13개 통과. 이름 선택에 따른 개인 카드, 6개 학생 context와 교사 context 동시 사용, 시각 입력·오류 수정·순서 배열·완료·공유, 홈 왕복, 이름 변경·새로고침, 느린 초기 접속, 드래그·키보드 이동, 작은 화면·모션 감소, 오프라인·응답 유실·서버 재시작·수업 종료를 포함합니다.
- `npm start`로 빌드된 화면과 API 실행, health·교사 접속·학급 연결·개인 카드·연습 판정을 직접 확인했습니다.
- 실제 명령 `teacher:password`, `seed:demo` 반복, `backup`, `dev`, `start`를 확인했습니다. 백업은 실행 중인 서버의 변경을 거절하며 서버 종료 후 수행합니다. 복원된 DB·그림·키에서 교사 접속이 유지되는 테스트를 포함합니다.
- 독립된 전체 코드 검토에서 확인한 중요 문제 3개를 실패 테스트로 재현한 뒤 수정했습니다. 이름 변경 실패 시 초안 유지, 늦은 충돌 응답이 최신 저장 상태와 수업 종료를 덮어쓰지 않기, 교사가 수정·업로드 중인 카드를 저장하거나 취소해야 수업 시작하기를 확인했습니다. [구현 판단과 남은 보완점](IMPLEMENTATION_NOTES.md)에 검토 결과와 설계상 선택을 기록했습니다.

## 아직 확인하지 못한 범위

- **WebKit/Safari:** 브라우저 실행 파일 설치가 필요합니다. 공식 다운로드 주소가 현재 실행 환경에서 HTTP 403 `Domain forbidden`으로 차단되었습니다. 테스트 assertion 실패가 아니라 환경 선행 조건 문제이며 Safari 지원을 검증했다고 주장하지 않습니다.
- **실제 태블릿 6대와 전자칠판:** 자동 검증의 독립 브라우저 context와 구분합니다.
- **학생 사용성, 조작 시간, 40분 수업 리허설:** 현장 검증이 필요합니다.
- **외부 HTTPS 서비스 배포, 환경 게시, 게시 후 새 머신 복원:** 수행하지 않았습니다.

## 환경 설정

브라우저 검증을 위해 `cdn.playwright.dev`, `playwright.download.prss.microsoft.com` 허용을 환경 설정 초안에 저장했습니다. 기존 package_managers 프리셋은 유지했습니다. `install_script`에는 확인한 고정 설치·빌드 명령을, `start_skill`에는 현재 체크아웃·데이터·프로세스 재시작과 기능 확인 지침을 함께 저장했습니다. 초안 저장은 실행 환경의 네트워크 적용이나 게시를 뜻하지 않습니다. 설정을 적용한 뒤 공식 브라우저를 설치하고 `npm run test:e2e`로 두 프로젝트를 다시 검사해야 합니다.

개발용 초기 비밀번호는 로컬 비공개 파일과 DB에서 관리하며 소스·캡처·설정 스크립트에는 값을 넣지 않습니다. 현재 클라우드의 로컬 개발용 비밀번호 파일은 `.local/teacher.password`이며 실제 수업에는 서버 종료 후 `npm run teacher:password`로 선생님이 정한 비밀번호를 설정합니다.

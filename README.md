# 시계는 째깍! 하루는 찰칵! ⏰📸

초등학교 1학년 수학 **시계 보기(몇 시, 몇 시 30분)**를 학생의 실제 하루 일과와 연결하는 학습형 웹앱 프로젝트입니다.

> 상태: **기획·수업 설계 단계**. 이 저장소에는 현재 완성된 웹앱 구현 코드가 없습니다.

## 프로젝트 목표

- 바늘시계에서 정각과 30분을 스스로 읽고 오류를 수정하기
- 학생이 직접 고른 일과 8가지를 시각과 연결하고 시간 순서대로 정리하기
- 각자의 하루를 공유하며 자신이 소중하게 여기는 시간이나 생활 다짐 이야기하기
- AI·디지털 도구를 수단으로 활용하여 **학습자 주도성(의도성·자기조절·자기성찰)**을 기르기

## 수업 활동

| 모드 | 수업 활동명 | 주요 기능 |
| --- | --- | --- |
| 연습모드 | **째깍! 읽어 봐** | 무작위 아날로그 시계 읽기 반복, 필요 시 힌트와 오답 자기수정 |
| 실전모드 | **착착! 맞춰 봐** | 8장 카드 뒤집기, 시계 읽고 시각 입력, 시간순 배열, 오류 자기수정 |
| 공유모드 | **찰칵! 들려줘** | 교사용 화면에서 완성된 일과표 공유, 실물 카드로 발표 |

기본 수업은 **도입 3분 – 전개 32분 – 마무리 5분** 구성입니다. 

## 학습자 제작 카드

- 학생마다 총 **8장**, **일어나기·잠자기 필수 + 6장 자유 선택**
- 그림은 아이가 직접 그리고, 카드 앞면에는 그림·일과 이름을 배치
- 뒷면에는 해당 일과를 나타내는 **바늘시계** 배치
- 태블릿에서 카드를 터치하면 앞면과 뒷면이 전환됨
- 학생별 실제 생활을 조사한 후 정각 또는 30분 시각으로 교육적으로 연결
- 8장 카드의 시간이 가능한 한 서로 다르게 배정되어 순서 배열에 혼동이 없도록 준비

## 구현 시 주의

6대의 학생용 태블릿과 교사용 대시보드 사이에 **실시간 공유**가 필요합니다. 브라우저 로컬 저장소만으로는 기기 간 동기화되지 않으므로 서버/실시간 데이터 저장소를 사용해야 합니다.

이 공개 저장소에는 학생 실명, 학생 그림, 생활 시각과 같은 **개인정보가 포함된 실제 학습 데이터를 업로드하지 않습니다.** 예시 데이터는 가명·가상 일과를 사용합니다.

## 현재 자산 상태

수업안 원본 PDF, DOCX, 이미지 및 카드 디자인 파일은 별도 작업물이며 이 첫 커밋에는 포함하지 않았습니다. 수업에서 사용할 이미지·그림이 완성된 뒤, 공개 권한을 검토해 필요한 자산만 추가합니다.
